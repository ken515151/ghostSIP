Import settings

Restores a settings file made by Export settings. This is a faithful restore:

  • All Configuration values are overwritten by the file.
  • The handset list is made to match the file exactly — handsets not present in the file are removed.
  • Everything is validated first; if anything in the file is invalid, nothing is changed.

Afterwards, press Reload Asterisk on the Configuration page to apply the regenerated telephony config.

Settings files contain the SIP, webhook and trunk passwords in plaintext. Store them like passwords.
